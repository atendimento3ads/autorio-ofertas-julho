# Autorio — Ofertas de Julho

Landing page de catálogo de ofertas (Chevrolet 0 km) da concessionária Autorio.

- Página estática (HTML + CSS), com um pequeno script de filtro de categorias.
- Sem dados sensíveis. Os links de WhatsApp usam um número placeholder (`55XXXXXXXXXXX`) que deve ser substituído pelo número oficial antes de publicar em produção.

## Estrutura
- `index.html` — a landing page
- `images-ofertas/` — banners, fotos dos modelos e logo

Feito por 3ADS.
